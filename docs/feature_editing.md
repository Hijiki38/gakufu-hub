楽譜編集機能は `App.tsx` の "Open Editor (PoC)" から `ScoreEditorPoc` をモーダル表示し、S3 上の最新版 PDF に手書き注釈を重ねて保存できる構成になっている。レンダリングは WebView + pdf.js、描画は React Native + SVG で実装され、保存時に注釈を PDF 本体へ焼き込み新バージョンとしてアップロードする。

### 対象ユーザー・利用場面
対象: ボウイングや指番号を即時共有したいパートリーダー／セクションメンバー。
利用シーン: 練習中に iPad 等で最新版譜面を開き、その場で修正を書き込みクラウドへ反映させる。

### 機能詳細要件
- 対象PDFの取得
  - ``list({ path: `data/${repo}/` })`` でリポジトリ内の PDF を更新日時順に並べ、最も新しいファイルを対象とする。
  - `getUrl` で署名付き URL を取得し、Expo FileSystem の `cacheDirectory` に `editor-latest.pdf` として保存。
  - pdf.js を埋め込んだ WebView を通じて 1 ページ目をブラウザキャンバスへ描画。
- 描画レイヤー
  - 描画ポイントは `Stroke` 配列で管理し、AsyncStorage (`score-editor:strokes:{repo}`) に永続化。最大 50 件まで保持。
  - ツール: 3 色ペン、Undo / Redo、クリアボタン。線幅は固定値 (内部的には保存時に 1.2 倍して PDF へ描画)。
  - タッチまたはスタイラス操作を PanResponder で検出し、PDF 表示に合わせて座標を正規化して保持。
- 保存処理 (`handleSave`)
  - キャッシュ済み PDF を `pdf-lib` で読み込み、現在ページにストロークを線として描画。
  - 新規キーは `computeNewKey` で `basename-annotated-{ISO8601}.pdf` を生成。
  - `uploadData` で `data/{repo}/` にアップロードし、完了後 `post({ apiName: DIFF_API_NAME, path: "diff" })` で差分 Lambda を同期呼び出し。
  - 保存完了後もエディタは開いたままで、同じストロークレイヤーを継続編集できる（PDF の再読込は行わない）。
- UI 制御
  - `diffStatus` テキストで差分処理結果を表示。
  - `saving` / `diffRunning` フラグにより保存ボタンを無効化し二重送信を防止。
  - モーダルを閉じる／リセットする操作はヘッダーのボタンで提供。

### 非機能要件・留意点
- 対応ページは 1 ページ目のみ。複数ページ編集・ページ切替は未実装。
- ストロークは SVG オーバーレイとして保持しているため、極端に長時間描画するとメモリ負荷が増す。Undo 50 件制限で軽減。
- オフライン時は既に取得済み PDF とストロークで作業できるが、保存と差分トリガーはオンライン前提。オフライン編集の詳細は `feature_offline.md` を参照。
- ペン太さ変更、消しゴム、スタンプ等の UI は今後の拡張余地として未実装。要件に合わせて追加が必要。
- 保存失敗時は Alert 表示のみで自動リトライ無し。ログ保全や再送キューは別途検討する。
